Promo code versus referral

Cloudways uses both terms, and they are not quite the same. A referral normally passes from one existing customer to someone they invite, using a link. A promo code is typed into a dedicated field during sign-up. TREVANTA is a promo code, so it goes in the Promo Code field rather than being attached through a link.

Where to enter TREVANTA

Start the sign-up on the Cloudways website. The form asks for your name, work email and a password, and it includes a field for a promo code. Type TREVANTA there in capitals and continue. Cloudways then walks you through verifying your email and, later, adding billing details. If you do not see the promo field, look for a link labelled with the words promo code on the form and open it.

Who it is for

Promo codes on managed hosting are normally intended for new customers. If you already have a Cloudways account, a new code generally will not apply to it. Agencies and freelancers who open an account for a client should enter the code on the client's new account at the moment it is created.

Checking the discount

After you sign up and add billing, the billing section of the Cloudways platform shows the terms applied to your account. Look there to confirm the promotion was recognised. Cloudways sets the size and length of any discount, and it can change them, so read what the sign-up page and billing screen show rather than relying on a number quoted elsewhere.

A practical tip

Choose your server and plan after the account exists, not before. Then the promo code is already in place when billing starts, and you are not left asking support to add it afterwards.
